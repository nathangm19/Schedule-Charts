# Schedule-Charts — agent rules

This repo produces Mortenson work deliverables (schedule dashboards/charts). All output
follows Mortenson brand standards — full digest + approved logo assets in the
`mortenson-brand` plugin (`nathangm19/cc-skills-marketplace`).

- **Palette**: primary blue `#007CC2`, dark blue `#004F8C`, text `#231F20`, grays
  `#808080`/`#E6E6E6`; chart accents `#769E2E` `#4F8B36` `#F9B300` `#F88900` (green/gold/
  orange map well to on-track / watch / late). Build categorical series from these first.
- **Type**: Franklin Gothic Medium (heads) / Franklin Gothic Book (body); web fallback
  `"Franklin Gothic Medium", "Libre Franklin", Arial, sans-serif`.
- **Logo**: never drawn, recreated, recolored, or AI-generated — embed the approved PNG files
  exactly as provided (white variant on dark backgrounds, 2-color/black on light), or ship
  without a logo. Never reconstruct the pillars in CSS/SVG.
- AI-assisted visuals for external distribution need OG Marketing / HQ Brand review first —
  flag it in the handoff when it applies.

## No AI look — every deliverable
Deliverables must read as Nate built them, not Claude. Full rules + checklist: `no-ai-tells`
skill, `work-products.md` (`research-knowledge@nate-skills`). The short version:

- **No default skeleton.** No Executive Summary → Key Findings → Recommendations → Next Steps
  unless the content needs it. No section that only summarizes another section, no closing recap.
- **No AI chrome.** No emoji, callout boxes ("Key insight"), colon titles, Title Case headings,
  gradient heroes, identical KPI-card rows with ↑ pills, tagline subtitles, AI "Insights"
  prose panels, or "Generated by / Built with" footers. Size panels by importance, not a grid.
- **Workbooks use live formulas** for totals, variances, rollups — not pasted values.
- **Set file metadata to the user.** openpyxl: `wb.properties.creator =
  wb.properties.lastModifiedBy = "Nate Mahlum"` plus a real title. PDFs (matplotlib /
  reportlab): `metadata={"Author": "Nate Mahlum", "Title": ...}`. Never ship "openpyxl" or a
  library name as the author.
- **Decks:** no Agenda / Key Takeaways / "Thank You, Questions?" slides; titles state the point.
- **Test:** would a PM believe Nate built it himself on a Tuesday?
- Style only. The AI policy above still applies — flag Marketing/Brand review when it does.
