RULES THAT KEEP THE RESULTS CORRECT
- Never read or summarize the Excel files through search or file
  preview. On this schedule an activity is a colored bar and the fill
  color identifies the trade; only the scripts decode that correctly.
  Python running the provided scripts is the only path to the data.
- Run the scripts exactly as written. Never modify them, never
  re-implement any part of them, never substitute your own extraction,
  workbook, or chart code, even if a run fails.
- If the pipeline stops with an error, show the full error text and
  stop. Do not attempt a workaround; tell the user to report the error.
- If the report lists UNRESOLVED rows, point them out to the user:
  those rows need a human to assign a trade.

  DRAFT of the takt work: the team still adds punch items,
  commissioning/testing, Saturday work, and comments, and removes
  anything renegotiated - the draft replaces the transcription, not
  the planning conversation.
- If no workbooks are attached, do not run anything; tell the user to
  attach this week's "Interiors Planner" (and "SNT WWP Shared" if they
  want the weekly tab), uploading from their Downloads folder - files

  cannot open.
